# Spotify Song Feature Case Study
This repository contains all materials needed to complete a case study on time series analysis of song feature data. 

## Notes
The PDFs "CS3_hook.pdf" and "CS3_rubric.pdf" contain important information, including relevant context, how to pass specs, and the deliverable for this case study.

The MATERIALS folder contains all the necessary data and scripts to complete the case study. 

The REFERENCES folder contains PDFs of helpful resources that are relevant to this case study. Sources include an introduction to the SARIMA times series model, an article on the presence of seasonality in music, and a research document on music features. 

You can find the repository of the original project this case study is based off of [here](https://github.com/stephaniediau/DS-4002-Project-2), if there is interest in the original data source.

However, note that just for the purposes of the case study, the data in the MATERIALS folder is perfectly adequate.
